# RP2040_CRSF_BAUD_REDUCER

Raspberry Pi Pico (RP2040) в роли преобразователя скорости линии CRSF.

## Назначение

Приёмник Crossfire/ExpressLRS отдаёт CRSF на 400 кбод (у ELRS — 420), полётник
ждёт 200. Pico стоит между ними и переносит кадры без изменения содержимого.

## Распиновка

| Сигнал | Пин Pico | UART | Направление |
| --- | --- | --- | --- |
| CRSF от приёмника | GP5 | UART1 RX | вход |
| CRSF к полётнику | GP0 | UART0 TX | выход |
| CRSF от полётника (обратный канал) | GP1 | UART0 RX | вход, по умолчанию выключен |
| CRSF в приёмник (обратный канал) | GP4 | UART1 TX | выход, по умолчанию выключен |
| Светодиод | GP25 | — | индикация приёма |

## Отличия от базовой конфигурации

Скорости 400000/200000, UART1 на входе и UART0 на выходе, обратный канал
выключен, 32 слота очереди.

## Сборка

```bash
pio run -e rp2040_crsf_baud_reducer
pio run -e rp2040_crsf_baud_reducer -t upload
```

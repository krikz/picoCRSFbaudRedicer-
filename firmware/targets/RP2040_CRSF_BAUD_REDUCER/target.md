# RP2040_CRSF_BAUD_REDUCER

Raspberry Pi Pico (RP2040) в роли преобразователя скорости линии CRSF.

## Назначение

Приёмник Crossfire/ExpressLRS отдаёт CRSF на 420 000 бод (ExpressLRS), полётник
ждёт 230 400. Pico стоит между ними и переносит кадры без изменения содержимого.
Скорость на выходе должна ТОЧНО совпадать с настройкой полётника.

## Распиновка

| Сигнал | Пин Pico | UART | Направление |
| --- | --- | --- | --- |
| CRSF от приёмника | GP9 | UART1 RX | вход |
| CRSF к полётнику | GP4 | UART0 TX | выход |
| CRSF от полётника (обратный канал) | GP5 | UART0 RX | вход, по умолчанию выключен |
| CRSF в приёмник (обратный канал) | GP8 | UART1 TX | выход, по умолчанию выключен |
| Светодиод | GP25 | — | индикация приёма |

## Отличия от базовой конфигурации

Скорости 420000/230400, UART1 на входе и UART0 на выходе, обратный канал
выключен, 8 слотов очереди, FIFO приёма UART 256 байт, неблокирующая печать
в USB-консоль.

GP0/GP1 на Pico — это USB, в варианте `rpipico` ядра Arduino-Pico там по
умолчанию сидит `Serial1`, поэтому CRSF-линии выведены на GP4/GP5 и GP8/GP9.

## Сборка

```bash
pio run -e rp2040_crsf_baud_reducer
pio run -e rp2040_crsf_baud_reducer -t upload
```

# Настройки

Все параметры задаются через макросы препроцессора. Значения по умолчанию лежат
в `firmware/include/crsf_baud_config.h`, значения таргета — в
`firmware/targets/RP2040_CRSF_BAUD_REDUCER/target_config.h` (подключается первым
и имеет приоритет).

Переопределить можно на уровне сборки:

```bash
pio run -e rp2040_crsf_baud_reducer \
  -D CRSF_BAUD_IN=420000UL -D CRSF_BAUD_OUT=200000UL
```

или в `platformio.ini`:

```ini
[env:rp2040_crsf_baud_reducer]
build_flags =
    ${env:rp2040_crsf_baud_reducer.build_flags}
    -D CRSF_BAUD_IN=420000UL
```

## Скорости

| Параметр | Умолчание | Смысл |
| --- | --- | --- |
| `CRSF_BAUD_IN` | `400000` | скорость от приёмника. 400000 — базовый CRSF, 420000 — ExpressLRS, 416666 — CRSF Rev10 |
| `CRSF_BAUD_OUT` | `200000` | скорость в полётник: та, которую полётник ждёт на входе CRSF |

## UART и пины

| Параметр | Умолчание | Смысл |
| --- | --- | --- |
| `CRSF_BAUD_IN_UART` | `2` | UART на входе: 1 = Serial1 (UART0), 2 = Serial2 (UART1) |
| `CRSF_BAUD_OUT_UART` | `1` | UART на выходе |
| `CRSF_BAUD_IN_RX_PIN` | `9` | GP9 — приём CRSF от приёмника |
| `CRSF_BAUD_IN_TX_PIN` | `8` | GP8 — передача в приёмник (обратный канал) |
| `CRSF_BAUD_OUT_TX_PIN` | `4` | GP4 — передача CRSF в полётник |
| `CRSF_BAUD_OUT_RX_PIN` | `5` | GP5 — приём CRSF от полётника (обратный канал) |
| `CRSF_BAUD_ECHO_ENABLE` | `0` | обратный канал полётник → приёмник |

Два UART должны быть разными — иначе сборка падает с ошибкой.

## Буфер и таймауты

| Параметр | Умолчание | Смысл |
| --- | --- | --- |
| `CRSF_BAUD_QUEUE_SLOTS` | `32` | сколько целых кадров в очереди (слот = 64 байта) |
| `CRSF_BAUD_FRAME_TIMEOUT_MS` | `20` | таймаут неполного кадра, мс |
| `CRSF_BAUD_RX_CHUNK` | `64` | сколько байт забирать из приёмника за один проход |

## Логи и индикация

| Параметр | Умолчание | Смысл |
| --- | --- | --- |
| `CRSF_BAUD_LOG_BAUD` | `115200` | скорость USB-консоли |
| `CRSF_BAUD_LOG_EVERY_FRAMES` | `100` | как часто печатать статистику; 0 = не печатать |
| `CRSF_BAUD_LED_ENABLE` | `1` | мигание светодиода при приёме |
| `CRSF_BAUD_LED_PIN` | `25` | GP25 |

## Статистика в логах

```
crsf: ok=1234 bad=0 dropped=0 in=29576 out=29576 q=0/32
```

- `ok` — принято валидных кадров;
- `bad` — отброшено (битый CRC или недопустимая длина);
- `dropped` — вытеснено из очереди (вход быстрее выхода);
- `in`/`out` — байты принято/отдано;
- `q` — занято слотов из доступных.
